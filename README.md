# Chatbot Pribadi Konsultasi Skripsi Berbasis AI

Chatbot konsultasi skripsi berbasis AI yang di-deploy menggunakan Hugging Face Spaces.

## Tech Stack
- Python 3.10+
- Gradio
- Hugging Face Spaces

## Cara Menjalankan Locally
```bash
pip install -r requirements.txt
python app.py
```

## Cara Deploy di Hugging Face Spaces
1. Buat Space baru di Hugging Face dengan SDK: **Gradio**
2. Hubungkan ke GitHub repository
3. Upload file `app.py` dan `requirements.txt`
4. Space akan otomatis berjalan

## Fitur
- Konsultasi panduan penulisan skripsi
- Panduan judul, metodologi, literature review, dll
