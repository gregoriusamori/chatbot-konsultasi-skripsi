# Chatbot Pribadi Konsultasi Skripsi Berbasis AI

Repositori ini dikembangkan untuk memenuhi Tugas Besar Individu Mata Kuliah **Cloud Computing** (Kode: UNISM.SI011) Program Studi Sistem Informasi, Universitas Sari Mulia Tahun Akademik 2026/2027 Ganjil.

## 📌 Deskripsi Singkat
Proyek ini bertujuan untuk membangun dan mengimplementasikan aplikasi chatbot pribadi konsultasi skripsi menggunakan teknologi cloud computing. Sistem dikembangkan menggunakan **Python (Gradio)** dan dideploy menggunakan platform cloud **Hugging Face Spaces**. Pemanfaatan cloud dilakukan agar aplikasi dapat diakses melalui internet secara real-time oleh mahasiswa untuk berkonsultasi mengenai panduan penulisan skripsi secara fleksibel.

## 🛠️ Teknologi yang Digunakan
* **Cloud Platform:** Hugging Face Spaces (Cloud PaaS)
* **Programming Language:** Python 3.10+
* **Framework UI:** Gradio
* **Version Control:** Git & GitHub

## 🌐 Arsitektur Cloud
USER  →  INTERNET  →  HUGGING FACE CLOUD INFRASTRUCTURE  →  CONTAINER (Python App)  →  AI / RULE-BASED BOT
